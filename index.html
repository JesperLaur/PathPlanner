Draw segments

Pick a tool, then click on the map. New segments are added to the end of the job.

Selected

Click a segment (with no tool active) to select it. Undo: Ctrl+Z. Stop drawing: Esc or right-click.

Placement

Drag the white crosshair to move the path. Drag the green handle at the end of the +y axis to rotate it. Unit and turn direction only change how the heading number is read; try both if the path doesn't line up with what's on the ground.

Export

Writes the origin, heading, UTM zone and segments into the job file. If you only moved or rotated the path, the rest of the file is kept exactly as it was.
